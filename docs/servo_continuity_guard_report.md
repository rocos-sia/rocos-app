# 单次 IK 连续性、参考偏离与反馈保护报告

日期：2026-11-06。主仓库基线 `bfc46de`，pin_ik `92e2d56`，使用当前工作区修改。测试环境为 Talon + MuJoCo，不涉及真实机器人。

## 结果

已增加三层检查及分类日志，保持正常周期一次 IK：

1. IK 候选相对上一接受解的连续性检查。
2. IK 候选相对限速参考的偏离检查，以及限速后下一状态的制动可行性检查。
3. 实际反馈位置、速度相对参考的跟随检查；原有反馈有效性、位置/速度范围、新鲜度和制动阶段位置跟随保护保留。

远离奇异姿态的三轮 60 s 运动全部完成；近奇异零位的三轮 10 s 和一轮 60 s 运动也全部完成，无 IK、跟随或通信保护故障。主动注入的不连续目标被拒绝并进入故障停止，未推进参考状态。最终代码重新通过六个回归套件，并重复完成远/近姿态各 10 s 和不连续目标负例。

这证明本次轨迹下的连续性改善和保护接入有效，**不等同于所有奇异位形、任意轨迹、严格 1 ms 截止时间或真实硬件的安全性验证**。仍观测到少量超过 1 ms 的调用和约 2–3 mm 的末端跟踪偏差，见后文。

## 实现与接纳规则

主要修改在 `src/servo_signal_processor.cpp`、`src/move_servo.cpp` 和现有日志模块；没有新增 HTTP/UDP 字段或结果码，没有修改 pin_ik 源码、求解模式、求解预算、硬件配置或保护阈值来放行测试。

正常笛卡尔周期保持如下顺序：

```text
实际反馈合法性/跟随检查
  → 输入位姿合法性检查 → 笛卡尔低通 → 一次 IK
  → 关节限位/连续性/参考偏离检查
  → 按当前参考 q、v、a 限速并检查下一状态可制动
  → 全部成功后提交 IK 状态、参考状态及制动轨迹
```

IK 初值改为上一周期接受的 IK 解 `s.filtered`，启动时仍为实际关节位置；限速参考 `s.q/s.v/s.a` 独立维护。被拒绝的候选不更新上一接受解，也不更新参考状态。制动轨迹先写入复用的暂存区，所有轴和最终检查通过后才整体提交，避免一个轴失败后沿用半更新的制动数据。

为保持修改范围小，笛卡尔低通起点仍由上一接受 IK 解的 FK 得到，没有另外引入位姿滤波器状态。Speed 与 1 ms 单次求解预算不变，也不在同周期重试 IK。首点仍有独立 IK/起点容差检查，所以首周期合计两次，随后普通周期一次，停止 Step 零次。

设 `dt` 为配置控制周期，`vmax_i` 为 Model 从 URDF 导入的额定速度，`amax_i` 为现有型号驱动配置的加速度。`E_i` 优先使用已有 `following_error`；为零时采用原反馈保护的默认尺度 `20 × vmax_i × dt`。

| 比较对象 | 本轮规则 | 诊断前缀与结果码 |
|---|---|---|
| 上一接受的 IK 解 | `abs(q_ik - q_ik_prev) ≤ vmax_i × dt` | `servo_ik_discontinuity`，`IkTrack (-2314)` |
| 当前限速参考位置 | `abs(q_ik - q_ref) ≤ E_i`，限制目标累计领先/偏离 | `servo_reference_deviation`，`MotionLimit (-2313)` |
| 当前参考位置、速度、加速度 | 用原有限速器计算下一状态，再由 `MakeServoBrake` 验证位置边界、速度包络及受加速度/jerk 约束的制动可行性；笛卡尔模式失败时明确拒绝 | `servo_reference_infeasible`，对外 `MotionLimit (-2313)`，日志另含底层失败原因与参考速度/加速度 |
| 实际反馈位置 | `abs(q_actual - q_ref) ≤ E_i` | `servo_feedback_position_error`，`NotFollowPositionCmd (-2203)` |
| 实际反馈速度 | `abs(v_actual - v_ref) ≤ 20 × amax_i × dt`；原有实际速度绝对上限检查同时保留 | `servo_feedback_velocity_error`，`OutRangeFeedback (-2206)` |

这里比较的是每周期接纳的 IK 目标变化，不是把实际反馈与目标的位置差限制为单周期行程；两种检查采用不同尺度。参考偏离限制也不声称目标必须在一个周期内到达。下一点是否可执行、可制动，仍依赖参考的速度、加速度、jerk 和关节边界。

本次 Talon 七轴 `vmax=3 rad/s`、`dt=0.001 s`、配置 `amax=10 rad/s²`，因此对应：连续性 0.003 rad、默认参考偏离/位置跟随 0.06 rad、速度跟随差 0.2 rad/s。加速度、jerk 来自现有型号配置，不是从标准 URDF 自动推导；这些软件接纳尺度不是已标定的硬件能力证明。

## 故障动作与清晰日志

IK 连续性、参考偏离、制动可行性或实际跟随异常会锁存原因，停止接纳后续运动目标，并请求沿最后有效参考受限制动；制动结束后保留故障，不将被拒绝目标作为定位运动执行。IK 求解失败也使用现有受限停止路径。首点违规仍直接拒绝。反馈非法、越界、过期以及下游控制器硬保护仍可立即终止运动；不能承诺硬保护触发时一定能完成平滑制动。

日志使用已有实时固定记录队列，后台格式化；不在控制周期中直接 printf 或同步写文件。每类比较打印关节编号（从 1 开始）、候选/实际值、比较基准、绝对差值和阈值。非通信保护使用 `servo_guard_stop`，不再误打印为通信故障。

最终版本在线负例实际日志：

```text
servo_ik_discontinuity: joint 1,
candidate=0.005834017, previous_accepted_ik=0.000000000,
abs_delta=0.005834017, limit=0.003000000 (joint units);
candidate rejected.

servo_guard_stop: IkTrack (-2314); controlled stop latched;
rejected command will not be applied; fault retained after stopping.
```

查看方式：现有诊断服务 `GET http://127.0.0.1:8082/api/logs?limit=100`，以及 App 控制台/日志文件。RCI 状态快照保留故障码，UDP 总故障标志置位；本轮没有改变 UDP 布局。

## 测试姿态与方法

每一轮均先关闭 RCI，再通过显式 MoveJ 定位，核验 STOPPED、实际位置误差小于 1e-4 rad并等待稳定，随后启动伺服。定位参数：速度 0.2 rad/s、加速度 0.5 rad/s²、jerk 2 rad/s³。没有让伺服限速器代替定位运动。

- 远离奇异姿态：`[0, -0.6, 0.4, 1.2, -0.3, -0.7, 0.2] rad`。初始最小奇异值约 **0.17559**；三轮运动中每 10 个 Step 抽样的最低值约 **0.17467**。
- 近奇异姿态：全零位，实际定位后的最小奇异值约 **1.53e-33**。60 s 扩展试验中抽样最小奇异值范围约 **1.65e-33～0.00161**，仍属于明显更差的条件数区域。

奇异值采用当前 m/rad 数值约定，是本次姿态对比指标，不是新增的运行保护阈值。独立 URDF FK/Jacobian 的正确性已在前一轮与实际 Model 对照验证；本轮保存实际起点、完整奇异值和每次 MoveJ 响应。

正常运动沿用之前的输入：各轴相对本轮起点叠加 0.01 rad 幅度、0.05 Hz、轴间相位差 0.1 rad 的正弦，5 s 渐入，经 FK 转为笛卡尔位姿，客户端以 1 kHz 发送。原有 0.1 rad 测试端退出条件保留。FK 的关节参数不是冗余 IK 唯一应返回的解。

## 尚存的限制

1. **不是硬实时验收。** 主对比中 13 次 Step 超过 1 ms，9 次 CartToJnt 墙钟耗时超过 1 ms；最大 Step 约 3.332 ms，最大 IK 约 3.257 ms。它们没有导致本轮求解失败或通信保护触发，但不能因此称为满足严格 1 ms 截止时间。本轮没有改工作线程调度或超时机制。
2. **跟踪误差仍需区分。** 按实际应用指令序号对齐，远离奇异三轮的最大实际 TCP 位置偏差约 2.03～2.05 mm、姿态偏差约 0.00718～0.00729 rad；近奇异 60 s 约 3.01 mm、0.00777 rad。这包含低通、限速和反馈跟随的滞后，不是 IK 求解残差。没有为这些偏差设置新的精度验收门槛，也未调整限速跟踪规律。
3. **不是所有近奇异轨迹都可接受。** 本次改善同时包含连续解热启动和候选检查；正常试验未触发候选拒绝，因此不能把改善全部归因于阈值拦截。不同方向、速度、采样率或位形仍可能安全拒绝，不能保证总能找到可接受解。
4. **不是 30 分钟长测或硬件认证。** 本轮覆盖指定轨迹的 60 s 重复测试和故障验证。导数配置沿用现有 Talon 仿真配置，未验证真实驱动能力。诊断复制与写线程也可能扰动调度，记录的耗时不是无测量开销基准。
