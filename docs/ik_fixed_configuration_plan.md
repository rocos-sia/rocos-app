# 固定构型约束 IK 独立验证方案

日期为 2026-11-09。本阶段在独立测试工程中实现和验证，计算预算为每次 1 ms，使用单核编译。

## 依据和目标

已有独立实验表明，Talon 七自由度机械臂以上一解作为下一次初值时，pin_ik 和 TRAC-IK 的 Newton 后端均出现约 0.00102 rad/圈的 J1 构型漂移。目标是同时保持局部解连续性和长期周期重复性。

## 固定约束

会话开始时记录经过检查的起始关节角 q_a，计算起点 Jacobian 的单位零空间向量 c。

```math
J(q_a)c=0,\quad \|c\|=1,\quad h(q)=c^T(q-q_a)=0
```

q_a 和 c 在整个测试会话内固定。每周期仍以上一接受解热启动，同时求解完整位姿和固定构型约束。

```math
T(q_k)=T_k,\qquad h(q_k)=0
```

## 求解方法

采用 Pinocchio 的模型、Data、FK 和 Jacobian，复用求解工作区。将六维 SE(3) 对数误差与标量构型误差合并为七维方程。设 M=T(q)^{-1}T_d，e=log6(M)，误差下降方向的 Jacobian 为 J_e=Jlog6(M^{-1})J_local。

```math
\begin{bmatrix}J_e(q)\\c^T\end{bmatrix}\Delta q
=\begin{bmatrix}e(q)\\-h(q)\end{bmatrix}
```

使用有界 Newton 迭代和回溯步长控制，检查关节范围、有限值、残差与增广矩阵退化。位置残差以米计，旋转和构型残差以弧度计。矩阵诊断以特征长度 1 m 归一化平移量，数值阈值属于测试配置。

一次外层调用完成整个求解。预算从入口开始计时，在 FK、Jacobian、分解、回溯和成功提交处检查截止时间。普通 Linux 调度中，单次算子和线程被抢占造成的墙钟超预算另行统计。首次失败结束用例并保留原始数据。

## 连续性与重复性

在 J 满行秩时，增广矩阵可逆等价于 c^T n(q) 非零，其中 n 为当前 Jacobian 的单位零空间方向。局部隐函数定理给出光滑映射 q=Q(x)。当整段轨迹位于同一单值解区域、关节范围和运动约束可行时，周期输入满足 Q(x(t+T))=Q(x(t))。

每次求解检查固定约束的绝对残差。归一化增广矩阵逆的范数有界时，相同目标处的解偏差由求解残差与条件数控制。上述保证依赖局部单值区域，退化或越界通过明确失败处理。

## 独立实验

- 使用已有 Talon URDF、非奇异起点和 XYZ 幅值 10、5、2.5 mm 的闭合轨迹，5 s 渐入，默认每秒 1000 点。
- 对照 pin_ik 原始 Newton、Speed，以及固定构型约束 Newton。TRAC-IK 原始 Newton 作为交叉参考。
- 所有轨迹用例采用 1 ms 单次预算。主对照运行 100 圈，新旧 Newton 增加 1000 圈长序列。
- 增加反向、直线往返、固定目标、位置姿态同时变化，以及不同采样密度对照。
- 主容差为 1e-5，增加 1e-6 对照。构型残差使用独立容差 1e-10 rad。
- 每周期仅一次外层 IK 调用，验证结果的 FK 和 Jacobian 统计放在求解计时之外。
- J=10000 为现有 App 配置基线，独立 IK 实验输入仅包含模型、位姿和关节初值。

## 采集与验收

记录每周期返回码、求解墙钟时间、候选关节角、FK 误差、构型残差、最大单步关节变化、Newton 迭代次数、增广矩阵最小奇异值和接受状态。使用同一 URDF 的关节速度上限检查单周期候选变化。

逐圈比较相同目标相位的关节角，统计长期漂移斜率和闭合误差。固定约束版本要求构型误差在容差内，关节闭合误差有界，末端残差满足容差。计时报告包括 p50、p99、p99.9、最大值、超预算次数及失败率。

故障用例覆盖非法输入、关节越界和不可达目标，检查失败期间输出与固定构型参考的完整性。最终报告区分算法残差验证、预算检查和完整函数墙钟耗时，并给出所有失败样本。
